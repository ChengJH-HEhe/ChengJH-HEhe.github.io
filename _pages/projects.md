## Mx compiler

A compiler for Mx, a C-like educational language, written in **Java** for the Compiler Design and Implementation course.

- Implements memory-to-register promotion (Mem2Reg) and aggressive dead-code elimination (ADCE).
- Uses SSA-based register allocation.
- Achieves performance comparable to `-O2` in the course evaluation, as reported in my CV.

[Source code](https://github.com/ChengJH-HEhe/Compiler-Design-Implementation)

## Verilog CPU

A CPU implemented in **Verilog** for a Computer Architecture course.

- Implements the Tomasulo algorithm.
- Supports basic RISC-V integer instructions.

[Source code](https://github.com/ChengJH-HEhe/CPU-2024)

## Raft

A **Go** implementation of Raft for a course project in Principles and Practice of Computer Algorithms. Raft manages a replicated log and maintains consensus despite non-Byzantine failures, including network delays, partitions, packet loss, duplication, and reordering.

[Lab specification](https://pdos.csail.mit.edu/6.824/labs/lab-raft1.html)
